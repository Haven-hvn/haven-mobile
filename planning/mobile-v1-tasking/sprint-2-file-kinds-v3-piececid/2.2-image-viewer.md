# Task 2.2 — Image viewer (Coil)

**Assigned Role:** UX Engineer

## Context

`MediaKind.IMAGE` (jpg/png/webp/gif/heic) renders inline with Coil (FR-UI-2). Like VIDEO/AUDIO, plaintext bytes must live only in memory (Decision 2). Coil's typical model is `load("url" or File)`; that pattern is unsafe here because it might route through OkHttp's disk cache and end up writing plaintext. This task uses Coil's `ImageSource`/`ByteBuffer` fetcher paths to feed decrypted bytes into Coil without touching disk.

## Objective

Ship the `IMAGE` viewer for the kind dispatcher: fill-screen image with pinch-to-zoom, sourced from a `Flow<ByteArray>` plaintext stream fed into a Coil `ImageRequest` via a custom `Fetcher`.

## Interface Contracts

- Extends the `PlaintextSource` sealed interface in `feature-watch` — `Image` variant.
- Coil version pinned by the version catalog from Task 0.1 (`gradle/libs.versions.toml`). Do not import a different version.
- Custom Coil `Fetcher` / `FetcherFactory` for the Haven-decrypted source lives in `haven.mobile.feature.watch.image` — do not put it in `core-crypto` or `core-cache`.

## Constraints

- **Decision 2:** no disk cache. Configure the per-request `ImageLoader` with `diskCache = null` and `respectCacheHeaders = false`. Memory cache is fine (and desirable — pinch-zoom re-decode is expensive).
- **Large images:** the fixture set includes HEIC 5000×5000. Use Coil's built-in downsampling. Aim to keep peak memory under 3× the decoded target size.
- **GIF playback:** enable Coil's animated-image decoder (opt-in via a Coil dependency). Static images unaffected.
- **HEIC:** Android's built-in HEIC decoder covers API 28+; on API 26/27 fall back to displaying an error state (log a `HavenError` code — coordinate with API Designer to name it). This is a rare, non-blocking degradation.
- **Zoom / pan:** Material 3 gesture-friendly patterns; do not pull in a large gesture library. Compose `Modifier.pointerInput` is sufficient.

## Out of Scope

- Slideshow / next-prev-image navigation.
- EXIF display.
- Image editing.
- Share sheet (share = SAF export, and that's `FILE` kind's territory).

## Acceptance Criteria

- [ ] For an `IMAGE` fixture, image renders correctly with pinch-to-zoom.
- [ ] No plaintext file created (assertion in an instrumented test that snapshots `cacheDir` before/after).
- [ ] GIF fixture animates.
- [ ] 5000×5000 HEIC fixture doesn't OOM on a Pixel 6 profile.
- [ ] Airplane-mode replay works.
- [ ] `./gradlew :feature-watch:connectedAndroidTest` passes.

## Validation Steps

```bash
./gradlew :feature-watch:connectedAndroidTest
```

Manual: view each of jpg / png / webp / gif / heic fixtures; verify zoom on each; verify GIF animates; verify a large HEIC doesn't hitch.
