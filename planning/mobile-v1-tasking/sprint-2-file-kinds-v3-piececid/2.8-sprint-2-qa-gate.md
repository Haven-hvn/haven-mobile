# Task 2.8 — Sprint 2 QA gate

**Assigned Role:** Code Reviewer / QA Gate

## Context

Sprint 2 delivers the other four `MediaKind` viewers, SAF export for `FILE`, v3 batch decrypt, and PieceCID verification. Before Sprint 3 starts, review confirms exit criteria.

## Objective

Sign off — or reject with a blocker list — Sprint 2 against the exit criteria in `sprint-2-file-kinds-v3-piececid/README.md`.

## Interface Contracts

None (review task). Reviewer verifies the `HavenAol.decryptAll` addition matches Task 2.4's brief, the `PieceCidVerifier` binding is the real implementation, and no post-v1 features leaked in.

## Constraints

- **Do not fix issues — file them.**
- **Blocker vs nit:** decision violations + FR non-satisfaction = blocker; style/nits = fileable.
- **Plaintext-on-disk audit:** re-run the Sprint-1 grep, extended to `feature-watch` including SAF-export code. The SAF export is the ONE allowed disk write, and it must go directly to the user-selected `Uri`, not to app-owned dirs first.
- **Canister-call-count audit:** run the v3 batch scenario and confirm one call per gate epoch (per Decision 7).
- **PieceCID verification audit:** confirm the `PieceCidVerifier` binding is NOT the Sprint-0 no-op.

## Out of Scope

- Sprint 3+.
- Sibling projects.

## Acceptance Criteria

- [ ] Every Sprint-2 task's acceptance-criteria checklist verified pass/fail; matrix produced.
- [ ] Coverage: `./gradlew koverVerify -Phaven.coverage.enforce=true` passes.
- [ ] All five `MediaKind`s exercised end-to-end manually against real fixtures.
- [ ] v3 batch canister-call count verified (one per gate epoch).
- [ ] PieceCID verify: fault-injected corrupt piece triggers retry via a different provider, success on retry.
- [ ] SAF export: warning appears once; disabled correctly for integrity-failed items.
- [ ] Written go/no-go recommendation posted with per-task pass matrix.

## Validation Steps

cd mobile-app
./gradlew clean build
./gradlew koverVerify -Phaven.coverage.enforce=true
./gradlew :app:connectedAndroidTest
grep -rEn 'FileOutputStream|RandomAccessFile|Files\.write|writeBytes' \
