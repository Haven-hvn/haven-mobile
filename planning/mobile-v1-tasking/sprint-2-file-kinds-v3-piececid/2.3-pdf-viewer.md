# Task 2.3 — PDF viewer (PdfRenderer)

**Assigned Role:** UX Engineer

## Context

`MediaKind.DOCUMENT` (`.pdf` in v1) renders inline via Android's system `PdfRenderer` (FR-UI-2). `PdfRenderer` requires a **seekable file descriptor** (`ParcelFileDescriptor`) — but Decision 2 forbids plaintext on disk. The escape hatch: `MemoryFile` (`ashmem`) — an in-memory backing store that produces a `ParcelFileDescriptor`. `PdfRenderer` accepts it. Plaintext lives only in RAM, satisfying the invariant.

## Objective

Ship the `DOCUMENT` viewer for the kind dispatcher: paged PDF display with pinch-to-zoom, sourced from decrypted bytes held in a `MemoryFile`. No temp file on disk at any point.

## Interface Contracts

- Extends the `PlaintextSource` sealed interface in `feature-watch` — `Document` variant.
- Uses `android.graphics.pdf.PdfRenderer` + `android.os.MemoryFile`. No third-party PDF SDK.

## Constraints

- **Decision 2:** the plaintext bytes MUST live in a `MemoryFile` (ashmem), never in a regular file. Verified by an instrumented test that inspects `cacheDir` and `filesDir` deltas.
- **Memory ceiling:** a large PDF (test with 200 MB fixture) must not put the app over the OOM threshold on a Pixel 6. If the PDF exceeds a configured limit (say 250 MB), fall through to a "Save & Open with…" fallback identical to `FILE` kind (Task 2.5). The threshold is a `PdfViewerConfig(maxInMemoryBytes: Long)` injected from `:app`; default 200 MiB.
- **Zoom / pan / page nav:** paginated horizontal or vertical scroll (choose one; horizontal matches most PDF readers). Include a page-jump surface for docs > 20 pages.
- **Text selection is out of scope for v1.** `PdfRenderer` doesn't expose it easily.

## Out of Scope

- Annotations, form-filling.
- OCR.
- Table-of-contents outline (post-v1 nice-to-have).
- Search-within-doc.
- Non-PDF documents (`.docx`, `.odt` — those are `MediaKind.FILE` and get SAF export).

## Acceptance Criteria

- [ ] For a `DOCUMENT` fixture (`.pdf`), rendering shows correct page 1 with pinch-to-zoom.
- [ ] No plaintext file created (instrumented test asserts `cacheDir`/`filesDir` deltas).
- [ ] A 200 MB fixture PDF renders; a 300 MB fixture PDF falls through to SAF export path (Task 2.5).
- [ ] Airplane-mode replay works.
- [ ] `./gradlew :feature-watch:connectedAndroidTest` passes.

## Validation Steps

```bash
./gradlew :feature-watch:connectedAndroidTest
```

Manual: view a small PDF (< 5 MB), a medium (~50 MB), a large (~250 MB) — verify small/medium render, large falls through.
