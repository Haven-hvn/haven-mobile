# Task 1.10 — Sprint 1 QA gate

**Assigned Role:** Code Reviewer / QA Gate

## Context

Sprint 1 delivers Library, Watch (video), Settings v1, v1 gate decrypt, Room mirror, disconnect cleanup, and the 80% coverage floor on the four gated modules. Before Sprint 2 starts, review confirms exit criteria are met.

## Objective

Sign off — or reject with a concrete blocker list — Sprint 1 against the exit criteria in `sprint-1-library-watch-mvp/README.md`.

## Interface Contracts

None (review task). Reviewer verifies all project README §4 contracts still hold and new interfaces introduced this sprint (`MediaRepository`, `SettingsRepository`, `SecurityCleanup`, `HavenCipher`, `AesKeyCache`, `GateKeyCache`, `ArkivClient`) match their task briefs.

## Constraints

- **Do not fix issues — file them.**
- **Blocker vs nit:** anything violating a numbered Decision in project README §5 or a numbered FR in `MOBILE_V1_REQUIREMENTS.md` §5 that Sprint 1 was supposed to satisfy is a blocker.
- **Coverage floor is a hard gate.** Below 80% on any of the four modules = blocker.
- **Plaintext-on-disk audit** (Decision 2): grep the four content-touching modules (`core-crypto`, `core-cache`, `core-cache-mirror`, `feature-watch`) for `FileOutputStream|RandomAccessFile|Files.write|writeBytes`. Any hit outside a test fixture is a blocker.

## Out of Scope

- Sprint 2+ code.
- Sibling projects.

## Acceptance Criteria

- [ ] Every Sprint-1 task's acceptance-criteria checklist verified pass/fail; matrix produced.
- [ ] Coverage: `./gradlew koverVerify -Phaven.coverage.enforce=true` passes across the four gated modules.
- [ ] Plaintext-on-disk grep is clean (no non-test hits).
- [ ] Airplane-mode manual flow: connect (with prior session persisted) → Library → tap cached video → play succeeds.
- [ ] Two-wallet manual flow: connect wallet A, populate mirror, disconnect, connect wallet B, verify A's DB and cache untouched.
- [ ] Disconnect wipes cleanly for the current wallet (verify per Task 1.8 acceptance).
- [ ] Written go/no-go recommendation posted with per-task pass matrix and blocker list.

## Validation Steps

```bash
cd mobile-app
./gradlew clean build
./gradlew koverVerify -Phaven.coverage.enforce=true
./gradlew :app:connectedAndroidTest        # or the smoke subset
grep -rEn 'FileOutputStream|RandomAccessFile|Files\.write|writeBytes' \
  core-crypto/src/main core-cache/src/main core-cache-mirror/src/main feature-watch/src/main \
  && echo "BLOCKER" || echo "plaintext-on-disk audit clean"
```
