# Task 1.5 — `feature-library`: grid/list of MediaItems

**Assigned Role:** UX Engineer

## Context

The Library screen is the primary post-onboarding surface. Web dApp parity target: `haven-dapp-main/src/app/library/page.tsx` + `haven-dapp-main/src/components/library/*`. It shows all `MediaItem`s the connected wallet owns, sorted by recency, filterable by search string, with a per-item "cache status" chip and a per-item badge for `MediaKind` icon. Tapping an item routes to `watch/{id}`.

Data source: `MediaRepository.observeLibrary(walletAddress)` (Task 1.3) — Flow-driven, refreshed via `MediaRepository.refreshLibrary(walletAddress)` on screen entry and pull-to-refresh.

**Design source (mandatory read before implementing):**
- `mobile-app/design/screens/library.md` — wireframes, grid vs list layouts, empty/loading/error states, redlines.
- `mobile-app/design/tokens.md` — colors, typography, spacing, elevation.
- `mobile-app/design/components.md` — cache-status chip, `MediaKind` badge, search field, pull-to-refresh spinner.
- `mobile-app/design/a11y.md` — tap-target sizes, screen-reader labels, focus order.

If any acceptance criterion below has no answer in the design source, stop and file a design follow-up with the Product / UI Designer — do not invent a UI decision.

## Objective

Build the Library Compose screen and its `@HiltViewModel`. Ship both **grid** and **list** layouts with a user-toggleable switch (persistent per-install via DataStore — but that pref is *outside* the three keys Room mirror owns; add a new key `library.layout` scoped to this feature module's own DataStore-key extension).

## Interface Contracts

- Route id: `library` (project README §4.8).
- Package: `haven.mobile.feature.library`.
- Public entry point: `libraryRoute(navController: NavController)` NavGraphBuilder extension.
- Uses `MediaRepository`, `SettingsRepository`, `WalletSession` via Hilt-injected `@HiltViewModel`.
- Tapping an item calls `navController.navigate("watch/${item.id}")`.

## Constraints

- **Compose only, Material 3.**
- **Offline-first (Decision 9).** First frame renders from Room mirror if the DB has rows for this wallet, even with no network. Refresh runs in the background on entry.
- **No direct Arkiv calls from the ViewModel.** Everything flows through `MediaRepository`.
- **Search/filter parity with web dApp:** case-insensitive substring on `title` + `description`. If the web dApp adds tag filters later, they're post-v1.
- **`MediaKind` icon set:** map each `MediaKind` to a Material icon (or a project icon set). Icons ship as vector drawables in `feature-library/src/main/res/`. Do NOT hardcode Unicode emoji.
- **List/grid state key:** `library.layout`, stored in `haven-settings.preferences_pb`. This is the ONE new key `feature-library` may add outside the Room mirror's three keys — declare it in this module and expose only via the module's own repository-thin function.
- **Empty state:** distinguish "wallet has no items" from "not yet loaded" from "load failed" — three visually distinct states. Test each.
- **Loading state:** show a skeleton or shimmer only when Room is empty AND a refresh is in flight. If Room has cached rows, render them and let the refresh happen invisibly.
- **Pull-to-refresh:** Material 3 `PullToRefreshBox`. Refresh calls `refreshLibrary`.

## Out of Scope

- Any post-v1 discovery UI (featured, paste-address, QR, NFC).
- Multi-select, batch actions.
- Sort order beyond recency (v1 spec).
- Content-detail pane inside library (tap → dedicated Watch route).

## Acceptance Criteria

- [ ] Library screen renders both grid and list layouts; toggle persists across process death.
- [ ] With no network, screen renders cached items within 400 ms of route entry (measured with `androidx.tracing` Trace sections).
- [ ] Search filter narrows results correctly and clears without state loss.
- [ ] Empty, loading, and error states each render distinctly (unit test the state → composable mapping).
- [ ] Tapping an item navigates to `watch/{id}`.
- [ ] Cache-status chip reflects `ContentCacheStatus`; `MediaKind` badge reflects the enum.
- [ ] `./gradlew :feature-library:assemble` passes.

## Validation Steps

Instrumented tests using `androidx.compose.ui.test.junit4`:

```bash
./gradlew :feature-library:connectedAndroidTest
```

Manual: connect a wallet with ≥5 items, verify layout toggle, search, pull-to-refresh, and offline-first behavior with airplane mode.
