# Task 0.5 — `core-haven-aol` smoke-ping over `ic-kotlin`

**Assigned Role:** Domain Specialist — ACL / Haven-AOL

## Context

Haven-AOL is the Internet Computer canister that gates content decryption. In v1 the mobile app calls it via `ic-kotlin` (Decision 5), which is a sibling composite-build project (`../ic-kotlin`). The web dApp reference implementation lives at `haven-dapp-main/src/lib/haven-aol/*` — it dispatches to v1 or v3 metadata paths, manages nonces, and caches unwrapped keys.

Sprint 0's ACL work is **not** the real decrypt path. Sprint 0 only needs a **smoke-ping** that proves the mobile process can reach the canister via `ic-kotlin`, encode a Candid argument, decode a reply, and expose a boolean "canister reachable" result for the Debug tab (Task 0.8). Real v1 decrypt lands in Sprint 1 (Task 1.5); v3 batch lands in Sprint 2 (Task 2.4).

`ic-kotlin/README.md` shows the transport pattern: `IcAgent(OkHttpTransport(url, OkHttpClient()))`, `agent.call(canisterId, method, arg)`, decode reply with `CandidDecoder`.

## Objective

Provide `core-haven-aol` with a callable "is the canister reachable" ping and the skeleton of the future `HavenAol` interface so downstream Sprint 1 tasks have a stable target to compile against.

## Interface Contracts

Declare (empty bodies OK for the non-ping methods — Sprint 1 fills them in):

```kotlin
package haven.mobile.core.haven.aol

interface HavenAol {
    /** Real decrypt — implemented in Sprint 1 (Task 1.5) + Sprint 2 (Task 2.4). Throw NotImplementedError for now. */
    suspend fun decrypt(item: MediaItem, session: WalletSession): Result<ByteArray>

    /** Cached verification key for offline attestation — implemented in Sprint 3. Throw NotImplementedError for now. */
    suspend fun verificationKey(): Result<ByteArray>

    /** Sprint 0 deliverable: cheap round-trip that proves connectivity + Candid handshake. */
    suspend fun ping(): Result<PingResult>
}

data class PingResult(
    val canisterId: String,
    val roundTripMs: Long,
    val replyBytesLen: Int
)
```

- Configuration: `HavenAolConfig(val canisterId: String, val icHost: String)` — injected via Hilt from `:app`, not hardcoded in this module.
- Hilt binding: `HavenAol` bound as `@Singleton` from `haven.mobile.core.haven.aol.HavenAolDiModule`.
- Nonce, verification-key cache, gate-key cache, AES-key cache are Sprint-1+ concerns; do not create their surfaces here.

## Constraints

- **Decision 5:** all canister I/O goes through `ic-kotlin`. No parallel `HttpAgent`-alike. No direct raw HTTP to `ic0.app`.
- **Ping method choice:** use the canister's cheapest exported method — a query for the Haven-AOL Candid interface, e.g. `get_verification_key` or the canister's status/health method (confirm the exact method name from the canister's `.did` file before implementing; if none is obvious, use `__get_candid_interface_tmp_hack` which every canister exposes). Ping is a read-only query, not an update call.
- **Timeouts:** `roundTripMs` MUST be measured wall-clock around the `agent.call/query` invocation. Do not include DI resolution or Candid encoding of a static empty tuple.
- **No retries in Sprint 0.** A single query. Timeouts and retry logic land with the real decrypt in Sprint 1.
- **Failure surfaces `Result.failure(HavenError.X)`** — pick or add the appropriate subclass in `core-domain` (coordinate with API Designer if a new code is needed). Do not throw across module boundaries.
- Dispatcher: run on `@IoDispatcher`.

## Out of Scope

- Real v1 or v3 decrypt.
- Nonce management (`haven-aol-nonce.ts` port).
- Any AES key cache, gate-key cache, verification-key cache (Sprint 1 / 3).
- Candid parsing of Haven-AOL's business methods.

## Acceptance Criteria

- [ ] `HavenAol` interface + `PingResult` data class at the exact FQCNs above.
- [ ] `ping()` calls the canister via `ic-kotlin` and returns `Result.success(PingResult(...))` when reachable.
- [ ] Unit test with a stubbed `IcAgent`-like transport confirms: happy path returns `PingResult`; transport error returns `Result.failure(HavenError.<code>)`.
- [ ] The Debug tab (Task 0.8) can invoke `ping()` and display `roundTripMs`.
- [ ] `./gradlew :core-haven-aol:assemble :core-haven-aol:testDebugUnitTest` passes.
- [ ] `decrypt()` and `verificationKey()` throw `NotImplementedError` with a comment naming the sprint that fills them in.
