# Task 0.1 — Gradle skeleton, composite builds, version catalog

**Assigned Role:** Scaffolding Engineer

## Context

Haven Mobile v1 is an Android app that will consist of ~15 Kotlin modules living directly under `mobile-app/`. Three sibling projects already exist in the same repo and must be consumed via **Gradle composite builds** (not published artifacts): `foc-local-first-android`, `ic-kotlin`, and `reown-kotlin-develop`. There is no root-level Android Gradle setup yet; this task stands one up.

The project has adopted **Hilt** for DI, **Kotlin 2.x**, **JDK 17 toolchain**, current-stable AGP, `minSdk=26`, `targetSdk=34`. Version catalog is mandatory; every dependency version must live in `gradle/libs.versions.toml`. Convention plugins for the Android library / Android application / Kotlin library / Compose targets go under `build-logic/`.

## Objective

Stand up an empty-but-buildable Android project rooted at `mobile-app/` whose module graph exactly matches the layout in the project README §4.1, with composite builds wiring in the three sibling projects, a centralized version catalog, and convention plugins that make new-module setup a one-liner.

## Interface Contracts

You MUST honor these exactly (from the project README):

- Directory layout of §4.1 (all 15 modules present as empty Gradle projects).
- Kotlin package roots of §4.2 (`haven.mobile.app`, `haven.mobile.core.<name>`, `haven.mobile.feature.<name>`).
- Version catalog file: `gradle/libs.versions.toml`.
- Composite-build includes for: `../foc-local-first-android`, `../ic-kotlin`, `../reown-kotlin-develop`.
- Convention plugins live in `build-logic/` and are consumed via `plugins { id("haven.android.library") }` (or equivalent — you choose the plugin ids, but keep them namespaced under `haven.*`).

## Constraints

- **Decision 6 (composite builds).** Use `includeBuild(...)` in `settings.gradle.kts`. Do NOT reference these projects by Maven coordinates.
- **Decision 13 (Hilt).** Wire the Hilt / kapt / ksp plugins in the relevant convention plugin so per-module boilerplate is one-line.
- **Decision 14 (Kotlin 2.x, JDK 17).** Set the JVM toolchain to 17 in the convention plugins.
- No module may compile in `main/` for now beyond a package-info stub — the goal is *shape*, not content.
- Feature modules must depend on `core-domain` at minimum; do not add other cross-module dependencies speculatively.
- `settings.gradle.kts` must set an explicit `rootProject.name = "haven-mobile"`.

## Out of Scope

- Any application logic, ViewModels, screens, or interfaces beyond package declarations.
- DI graph beyond installing plugins (Task 0.2 owns the actual `HavenApplication` and modules).
- CI configuration (Task 0.7).
- Signing config (Task 0.7 owns the placeholder).
- Any dependency on Room, Media3, Coil, PdfRenderer, Compose beyond wiring the version catalog entries — actual usage arrives in later sprints.

## Acceptance Criteria

- [ ] From a clean checkout, `./gradlew :app:assembleDebug` succeeds without errors.
- [ ] `./gradlew projects` lists all 15 modules (`app`, `core-domain`, `core-wallet`, `core-haven-aol`, `core-arkiv`, `core-crypto`, `core-attestation`, `core-cache`, `core-cache-mirror`, `core-security`, `feature-onboarding`, `feature-library`, `feature-watch`, `feature-community`, `feature-settings`).
- [ ] `./gradlew help --task :ic-kotlin:ic-agent:help` resolves (proves composite build is wired for `ic-kotlin`). Equivalent proof works for `foc-local-first-android:foc-cache` and one Reown module.
- [ ] Every module has `namespace` set to its package root from §4.2.
- [ ] `gradle/libs.versions.toml` contains version entries for: Kotlin, AGP, Hilt, kotlinx-coroutines, kotlinx-serialization, Compose BOM, Room, DataStore, Media3, Coil, OkHttp, JUnit 5, Turbine, MockK.
- [ ] Convention plugins in `build-logic/` cover at least: `haven.android.application`, `haven.android.library`, `haven.android.compose`, `haven.kotlin.library`.

## Validation Steps

```bash
cd mobile-app
./gradlew --stop
./gradlew projects
./gradlew :app:assembleDebug
./gradlew help --task :ic-kotlin:ic-agent:help
./gradlew help --task :foc-local-first-android:foc-cache:help
```

Then confirm by inspection that `settings.gradle.kts` contains three `includeBuild(...)` lines and that `build-logic/` contains the four convention plugins.
