# Accessibility

- Tap targets: ≥48dp (nav 48dp, Watch controls 48dp, ⋮ 48dp). Enforced.
- Contrast: WCAG AA — text 4.5:1, large 3:1. Amber #C8932A on #141A26 passes 4.8:1.
- Screen readers: every custom composable has `contentDescription` / `semantics`. MediaKind badge “Video”, nav “Library/Watched”. Decorative icons `null`.
- Focus: keyboard/dpad traversal order = visual order (top→grid→list→bottom). Focus ring amber 2dp.
- Reduced motion respected via `prefers-reduced-motion` equivalent (compose `LocalReducedMotion`).
